## About MAICoS

**MAICoS** is an object-oriented **Python** toolkit for analyzing the structure and dynamics of interfacial and confined fluids from molecular simulations. Combined with [MDAnalysis](https://www.mdanalysis.org), MAICoS enables the extraction of density profiles, dielectric constants, structure factors, and transport properties from trajectory files generated by LAMMPS, GROMACS, CHARMM, or NAMD simulations.

MAICoS is designed both for beginners in molecular simulations with no prior Python experience—offering a descriptive **Command Line Interface (CLI)**—and for experienced users who can use the **Python API** for day-to-day analysis or build their own workflows for interfacial and confined systems.

## 🚀 Key Features

- **Easy to use**: Simple Python API and CLI for common analysis tasks
- **Powerful**: Comprehensive set of analysis modules for interfacial systems
- **Flexible**: Works with major MD simulation packages (LAMMPS, GROMACS, CHARMM, NAMD)
- **Well documented**: Extensive documentation with tutorials and examples
- **Open source**: Released under GNU General Public License v3.0

## 📦 MAICoS Ecosystem

The MAICoS project includes several related tools:

### [maicos](https://github.com/maicos-devel/maicos) - Core Analysis Package
The main MAICoS toolkit for analyzing interfacial and confined systems, featuring:
- Density profiles (planar, cylindrical, spherical)
- Dielectric properties and spectra
- Dipolar order parameters
- Velocity and temperature profiles
- Pair distribution functions
- Small-angle X-ray scattering (SAXS)

### [solvate](https://github.com/maicos-devel/solvate)
Solvate confined geometries for MD simulations.

### [scatterkit](https://github.com/maicos-devel/scatterkit)
SAXS and other scattering analysis of molecular dynamics simulations.

### [spectrakit](https://github.com/maicos-devel/spectrakit)
Spectral analysis tools for molecular dynamics simulations.

## 💻 Quick Start

Install MAICoS using pip:

```bash
pip install maicos
```

Or with conda:

```bash
conda install -c conda-forge maicos
```

### Basic Example

```python
import MDAnalysis as mda
import maicos

u = mda.Universe("conf.gro", "traj.trr")
dplan = maicos.DensityPlanar(u.atoms).run()

# Access results
density_profile = dplan.results.profile
bin_positions = dplan.results.bin_pos
```
